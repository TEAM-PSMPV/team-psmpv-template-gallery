# Changelog

Notable changes to this project are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and releases should use semantic versioning where practical.

## Unreleased

### Added

- Restaurant directions for Stackhouse Burgers, Tamra, and Saanjh, plus the Shree Kusbal Ayurvedam healthcare direction.
- A responsive bento-box presentation with a five-site floating hero collage and reduced-motion-aware parallax effects.
- Supplied full-page previews for Casa Mare Goa, Devdaar House, Mitti & Ember, Quality Mint, and Kesar Bagh Haveli.
- A five-position animated hero orbit that brings each featured template forward in sequence.
- GitHub Actions verification, CodeQL analysis, and protected Cloudflare deployment.
- Public repository security, governance, support, contribution, and beginner documentation.
- Dependabot configuration and structured issue, discussion, and pull-request templates.

### Changed

- Landing-page browsing now presents live templates in industry-led visual collections and omits Form Urban Hotel from the featured hotel collection.
- Preview screenshots now use full-image fitting on coordinated color frames, and gallery links open in isolated browser tabs.
- Production artifact validation now checks the generated Worker, Wrangler configuration, and static assets.
- Cloudflare deployment is independent of OpenAI-specific project metadata.

### Removed

- Unused OpenAI hosting metadata and workspace authentication helper.
