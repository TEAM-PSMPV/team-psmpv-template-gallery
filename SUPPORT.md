# Support

Use the appropriate public channel for non-sensitive requests:

- **Bug:** open a GitHub issue using the bug form.
- **Feature proposal:** open a feature request.
- **How-to question:** start a GitHub Discussion in Q&A.
- **General idea:** use the Ideas discussion category.
- **Security vulnerability:** follow [SECURITY.md](SECURITY.md) and report privately.

Before asking for help, search existing issues and discussions, read [INSTRUCTIONS.md](INSTRUCTIONS.md), and include the command, expected result, actual result, operating system, Node.js version, and a sanitized error message.

Never include API tokens, environment values, customer information, private URLs, or unredacted logs. Maintainers may close duplicate, unsupported, incomplete, or security-sensitive public reports and redirect them to the correct channel.
